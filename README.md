Tembea
Travel discovery site for Kenya — find destinations by region, explore country data, and plan your next trip.

Live site: http://127.0.0.1:5501/index.html

Tembea homepage screenshot

Features
Destination search and region filters with live result count
Country data from the REST Countries API (flags, capital, population, languages)
Fully responsive — mobile-first Tailwind CSS layout
WCAG AA accessible — keyboard navigable, screen reader tested
Dark mode via CSS custom properties
Tech Stack
HTML5 CSS3 Tailwind CSS JavaScript
